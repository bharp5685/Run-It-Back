# Run It Back

**Run It Back** is a 2D football kick return game created in Unity. The player controls a returner and must avoid defenders while reaching the end zone.

The game contains 11 levels. Each level adds another tackler and gradually increases the difficulty. Later levels use multiple defensive rows and lane-based defender behavior to make finding an open path more challenging.

## Controls

- **WASD** or **Arrow Keys** — Move the returner
- **R** — Restart the game after completing Level 11

## Gameplay

The goal is to reach the end zone without being tackled.

- Getting tackled restarts the current level.
- Reaching the end zone advances to the next level.
- Each new level adds another defender.
- Defender formations become more complex as the game progresses.
- Completing Level 11 wins the game.

## Features

- 11 progressively harder levels
- Lane-based tackler AI
- Multiple defensive formations
- Increasing returner speed as levels progress
- Tackle, touchdown, whistle, and victory sound effects
- Arcade-style football field and stadium presentation
- Level and controls UI
- Touchdown and tackle notifications
- Victory screen with restart functionality

## Development

This project was created in **Unity 6** as an individual 2D game programming project.

The gameplay and difficulty were adjusted through playtesting to create a more gradual difficulty curve between the early and later levels.

## AI Usage

ChatGPT was used as a development assistant for portions of the project, including explaining Unity and C# concepts, troubleshooting code, helping develop and revise gameplay scripts, improving defender AI, balancing difficulty, and reviewing the project during testing.

The game was implemented and tested in Unity, with gameplay values and design decisions adjusted through repeated playtesting.
